## 相談事項

各NM研究のreference cohortの年齢情報をグラフで表現したいと考えている。
縦軸に研究名、横軸を年齢とし、ボックスプロットで表現することを考えている。
ただし、半数くらいの研究は最大、最小、平均、標準偏差情報があるが、ある研究は最大値と最小値のみ、ある研究は平均と標準偏差のみといった感じで、不揃いである。
どのようにして最大値、最小値、平均、標準偏差が欠落した研究の年齢範囲を表現したらいよいだろうか？
ボックスプロットで表現できるだろうか？

## AIからの提案（2025-12-09）

- 結論: 純粋なボックスプロットは不適です。四分位がない（平均・SDのみ、最小・最大のみ）研究を混在させると解釈が難しくなります。代替として、横方向の区間＋点を用いるフォレスト型プロットを推奨します。

- おすすめの可視化（混在サマリ対応）
    - 共通軸: y=研究名、x=年齢。
    - full（min–Q1–median–Q3–max がある研究）: 通常の箱ひげ＋平均点を重ねる。
    - minmaxのみ: 最小–最大の細い線分（linerange）。
    - mean±SDのみ: 平均点＋太線で ±SD、細線で ±2SD（任意）を重ねる。
    - 記号・色・線幅で「サマリ種類」を凡例化し、見分けやすくする。
    - 可能なら点サイズに `n`（サンプルサイズ）を反映。

- 近似の扱い（必要時のみ、注記必須）
    - mean/SD → 四分位の近似（正規分布仮定）
        - Q1 ≈ mean − 0.6745 × SD
        - median ≈ mean
        - Q3 ≈ mean + 0.6745 × SD
        - これで「擬似ボックス」は描けますが、歪みが強い場合は不適切になり得ます。
    - min/max だけから四分位は推定しません（歪みに極めて弱い）。線分のみが無難。
    - min/max を近似で置きたい場合、n があれば正規近似で
        - min ≈ mean + SD × Φ^{-1}(1/(n+1))
        - max ≈ mean + SD × Φ^{-1}(n/(n+1))
        - 仮定が強いので、凡例や脚注で必ず明示。

- 実装の設計（データ整形）
    - 列例: `study, type, n, min, q1, median, q3, max, mean, sd`
    - `type` は `full | minmax | mean_sd`。
    - 描画レイヤは type ごとに出し分ける。

- R/ggplot2 の最小例（上記列を持つ前提）

```r
library(ggplot2)
library(dplyr)

# df: study, type, n, min, q1, median, q3, max, mean, sd

p <- ggplot() +
  # full: 箱ひげ（ひげ = min-max, 箱 = IQR, 中央線 = median, 点 = mean）
  geom_segment(data = df %>% filter(type == "full"),
               aes(y = study, yend = study, x = min, xend = max),
               size = 0.4, color = "grey50") +
  geom_rect(data = df %>% filter(type == "full"),
            aes(ymin = as.numeric(factor(study)) - 0.25,
                ymax = as.numeric(factor(study)) + 0.25,
                xmin = q1, xmax = q3, fill = "IQR"),
            color = "grey30", alpha = 0.3) +
  geom_segment(data = df %>% filter(type == "full"),
               aes(y = study, yend = study, x = median, xend = median),
               size = 0.8, color = "grey20") +
  geom_point(data = df %>% filter(type == "full" & !is.na(mean)),
             aes(x = mean, y = study, shape = "mean"), size = 2) +

  # minmax: 線分のみ
  geom_segment(data = df %>% filter(type == "minmax"),
               aes(y = study, yend = study, x = min, xend = max, color = "min–max"),
               size = 0.8) +

  # mean±SD: 太線=±SD、細線=±2SD（任意）、点=mean
  geom_errorbarh(data = df %>% filter(type == "mean_sd"),
                 aes(y = study, xmin = mean - sd, xmax = mean + sd, color = "±SD"),
                 height = 0.2, size = 1.3) +
  geom_errorbarh(data = df %>% filter(type == "mean_sd"),
                 aes(y = study, xmin = mean - 2*sd, xmax = mean + 2*sd, color = "±2SD"),
                 height = 0.1, size = 0.6, alpha = 0.6) +
  geom_point(data = df %>% filter(type == "mean_sd"),
             aes(x = mean, y = study, shape = "mean"), size = 2)

p +
  scale_y_discrete(limits = rev) +
  scale_color_manual(values = c("min–max" = "grey40", "±SD" = "#2C7BB6", "±2SD" = "#A6CEE3")) +
  scale_fill_manual(values = c("IQR" = "#FDB863")) +
  scale_shape_manual(values = c("mean" = 21)) +
  labs(x = "年齢", y = "研究", color = "区間の種類", fill = "箱", shape = NULL) +
  theme_bw()
```

- 表示上の工夫
    - 研究ごとに右側注記（用いた統計要約・近似の有無）。
    - 近似で作った箱（mean→IQR）は透明度を下げ、凡例に「正規近似」と明記。
    - `n` がある場合は点サイズで表現し、解釈に寄与させる。
