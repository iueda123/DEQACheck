# Dataset Name Normalization Keywords

> **Source**: `docs/20260116_keywords-for-dataset-name/20260116_Keywords-for-DatasetName.md` (Version: 20260210)

---

## 表記ルール

1. **公式略称を基本形とする**（例: `ABCD`, `ADNI`, `UK Biobank`）。
2. **バージョン/サブコホートはハイフンで接続**（例: `ABIDE-I`, `ADNI-3`, `HCP-A`）。
3. **スペース/ハイフンの揺れを統一**（例: `Cam-CAN`, `ENIGMA-CHR-P`）。
4. **MULTI-DATASET (UNSPECIFIED OR N>=10)**: 複数データセットの使用は明示されているが詳細不明、または 10 以上のデータセットを用いている場合。
5. **MULTI-SITE (N>=2)**: 「XX sites」「XX scan sites」「複数スキャナ/施設」を明示しており、サイト数ベースでの統合が主題の場合。
6. **SINGLE-SITE**: 単一施設・単一スキャナでの収集と読める場合。
7. **None (Pre-Trained NM)**: 事前学習済み normative model を使用し、データセット名を付与しない場合。
