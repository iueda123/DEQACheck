本検討では、**16種類**のニューロイメージングデータセットが実験に用いられています。

この数は、以前の検討における実験データ規模（7つのデータセット）を拡大したものです。使用された16のデータセットは表1に一覧されています。

このデータセット群は、ABCD、CAMCAN、CMI、CNP、FCON、HCP、HCPAG、HCPDV、HCPEP、IXI、NKI、OASIS3、OPN、PNC、TOP、およびUKBBを含んでおり、合計37,126スキャン、79のスキャナー、6歳から100歳までの広範囲のヒトの寿命をカバーしています。このデータセットの多様性は、大規模なマルチサイトの加齢規範モデリングのケーススタディとして適しています。



------------------

本検討で用いられた16種類のデータセットは、**大規模なマルチサイトの加齢規範モデリング**（normative modeling of aging）のための実験材料として使用されています。特に、148の皮質領域における**皮質厚の測定値**が解析に用いられています。

データセットの目的は、実験の段階に応じて、主に以下の二つのグループに分けられます。

### 1. 参照モデルの推定（開発フェーズ）

主に健常な参加者のみを含むデータセットは、参照規範モデル（reference normative model）の初期バージョンの推定に使用されました。

| データセット | 参加者の特徴（年齢層/患者数） | 備考 |
| :--- | :--- | :--- |
| **ABCD** | 9〜11歳 | 年齢範囲が比較的狭い（約10歳に集中）。 |
| **CAMCAN** | 18〜88歳 | - |
| **CMI** | 18〜88歳 | - |
| **FCON** | 8〜85歳。ADHD患者25名を含む。 | - |
| **HCP** | 22〜37歳 | - |
| **HCPAG** | 36〜100歳 | 加齢研究（Aging）。 |
| **HCPDV** | 8〜22歳 | 発達研究（Development）。 |
| **IXI** | 20〜86歳 | - |
| **NKI** | 6〜85歳 | - |
| **OPN** | 8〜58歳 | - |
| **PNC** | 8〜23歳 | - |
| **UKBB** | 44〜80歳 | 大規模データセット（約15,000人）。皮質厚が他のデータセットより平均的に高い傾向がある。 |

### 2. モデルの適応および異常検出（展開フェーズ）

以下の4つの臨床データセットは、主にモデルのデプロイメント（展開）フェーズにおいて、参照モデルをローカルデータに適応させる（再較正する）目的で用いられ、その後、異常検出実験の評価対象として使用されました。

| データセット | 参加者の特徴（患者数と疾患） | 実験目的 |
| :--- | :--- | :--- |
| **CNP** | 統合失調症(SZ) 49名、双極性障害(BD) 49名、ADHD 41名 | モデル適応、およびこれらの疾患の異常検出。 |
| **HCPEP** | 早期精神病(EP) 123名 | モデル適応、およびEPの異常検出。 |
| **OASIS3** | 認知症(DM) 271名、軽度認知障害(MCI) 51名 | モデル適応、およびDM/MCIの異常検出。DM患者は軽症例のみである。 |
| **TOP** | SZ 167名、BD 193名、大うつ病性障害(MDD) 31名、その他 107名 | モデル適応、およびこれらの疾患の異常検出。 |

**注意点:** モデル適応実験では、CNP、HCPEP、OASIS3、TOPに含まれる健常参加者のうち50%が参照モデルの再較正に用いられ、残りの健常参加者と患者がテストサンプルとして使用されました。

データセット全体の合計は、37,126スキャン、79のスキャナーを含み、6歳から100歳までの広範囲のヒトの寿命をカバーしています。この多様性が、大規模なマルチサイトの加齢規範モデリングのケーススタディに適しているとされています。

------------------


本検討で実験に用いられた全16種類のデータセットの総スキャン数は**37,126**です。

このうち、神経発達障害、精神医学的障害、または神経変性疾患と診断された参加者のスキャン数は合計1,107スキャンであるため、健常な参加者または対照群として利用されたスキャン数（N数）は、合計から患者数を引いた**約36,019**と推定されます。

特に、参照規範モデル（reference normative model）の初期バージョンを推定するために使用されたデータセットは、主に健常な参加者のみを含む以下の12種類です。

| :--- | :--- |
| ABCD | 10732 |
| CAMCAN | 647 |
| CMI | 893 |
| FCON | 1021 (患者25名を含む) |
| HCP | 1113 |
| HCPAG | 677 |
| HCPDV | 653 |
| IXI | 557 |
| NKI | 482 |
| OPN | 612 |

これらのデータセットだけでも、**33,815**のスキャンが含まれており、このうちFCONに含まれる25名のADHD患者を除いた大部分が、参照モデルの推定に用いられた健常者のデータです。
