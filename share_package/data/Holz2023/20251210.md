この検討では、ノーマティブ・デビエーションマップを統合するために、**4種類**のデータモダリティ（データセット）が用いられました。

これらのモダリティは、主に機能的磁気共鳴画像（fMRI）データと解剖学的（構造的）画像データに分けられますが、Linked ICA (LICA) 分析においては以下の4つのデータモダリティとして扱われました：

1.  **ネガティブな顔** (Negative faces)
2.  **ポジティブ/ニュートラルな顔** (Positive/neutral faces)
3.  **図形（形状）** (Shapes)
4.  **解剖学的画像** (Anatomy)

これらのデータは、まずノーマティブ・モデリングに適用され、その後、LICAを用いて構造的および機能的な逸脱パターンを統合するために使用されました。LICAは、これら4つのデータモダリティ全体にわたる非閾値化された規範的逸脱マップを統合するために使用されました。

---------------------

この検討で用いられた4種類のデータセット（モダリティ）は、主に**典型的な加齢に伴うパターンからの逸脱**をマッピングし、その後、構造的および機能的な逸脱パターンを統合するために使用されました。

各データセットの具体的な目的は以下の通りです。

### 1. 機能的磁気共鳴画像 (fMRI) 由来のモダリティ

以下の3つのモダリティは、参加者が感情顔マッチングタスクまたは感覚運動制御タスクを実行している間に取得された、脳活動の指標です。

| データセット | 元のタスクと目的 |
| :--- | :--- |
| **ネガティブな顔** (Negative faces) | **感情処理中の脳活動の逸脱**をマッピングするために使用されました。具体的には、**怒りや恐れ**の顔刺激に対する脳活動のデータです。このタスクは、扁桃体を含む顔処理ネットワークを頑健に誘発することが示されています。 |
| **ポジティブ/ニュートラルな顔** (Positive/neutral faces) | **感情処理中の脳活動の逸脱**をマッピングするために使用されました。具体的には、**嬉しい顔や中立的な顔**の刺激に対する脳活動のデータです。このモダリティの逸脱は、攻撃性との有意な関連性が確認されています。 |
| **図形（形状）** (Shapes) | 感情マッチングブロックと交互に提示された**感覚運動制御タスク**時の脳活動の逸脱をマッピングするために使用されました。このデータセットにおける年齢に関連した陽性逸脱は、**異常な認知知覚処理**の可能性を示唆しています。 |

### 2. 構造的磁気共鳴画像 (Structural MRI) 由来のモダリティ

| データセット | 元のタスクと目的 |
| :--- | :--- |
| **解剖学的画像** (Anatomy) | 高解像度の構造スキャンから得られたデータであり、**脳の構造**における典型的な加齢に伴うパターンからの逸脱をマッピングするために使用されました。具体的には、解剖学的特徴量として、各画像をテンプレートに一致させるために必要な組織の相対的な膨張または収縮の全体的な程度を定量化する**ヤコビアン行列式（Jacobian determinants: JDs）**が用いられました。 |

### 統合の目的

これらの4つのデータモダリティから導出された非閾値化された**規範的逸脱マップ**（Z変換されたスコア）は、その後のステップで**Linked ICA (LICA)**と呼ばれる手法により統合されました。LICAによる統合の目的は、機能的および解剖学的逸脱を横断的に統合し、**破壊的行動障害（DBD）の異質性の一部を解剖する**こと、そして**攻撃性に関連する神経学的特徴を特定する**ための包括的なモデルを提供することでした。

Q: Normative modelingに用いた健常者データセットのN数を教えてください。

A: 

ノーマティブ・モデリング（Normative modeling: GPRモデルの訓練）に用いられた**健常者データセット（コントロール群）**のN数について、ソースに基づきご説明します。

ソースによると、この研究では、**破壊的行動障害（DBD）の症例群（ケース）**と**コントロール群**の両方を含むコホート全体を使用してノーマティブ・モデリングが実行されました。

このモデル構築に使用された最終的なサンプルサイズは、機能的データ（fMRI）と解剖学的データ（構造スキャン）によって異なり、それぞれのサンプルサイズは以下の通りです。

1.  **機能的データ**（fMRI: 顔マッチングおよび図形処理）:
    *   最終的なサンプルサイズ：**N = 129** (ケース: 77名、コントロール: 52名)。
    *   したがって、機能的データにおける**健常者（コントロール）のN数は52名**です。

2.  **解剖学的データ**（構造スキャン/Jacobian determinants）:
    *   Linked ICAによる統合分析で使用されたサンプルは、機能的データと同じコホート（交差部分）であり、**N = 127** (ケース: 77名、コントロール: 50名) でした（ただし、解剖学的画像データセット全体は248名でしたが、ノーマティブ・モデリングで最終的に使用されたのはこの交差部分のサイズに近い数です）。
    *   もし、解剖学的特徴量のための**ノーマティブ・モデリングを健常者のみを基準コホートとして実施した場合**（感度分析としてより大きな解剖学的データセット $n=248$ のうち、コントロール群 $n=94$ を用いた場合）**のN数は94名**です。

### **主な分析（LICA統合）で用いられた健常者のN数**

ノーマティブ・モデリングが、機能的および解剖学的逸脱マップの統合分析（LICA）に直接利用された最終的なサンプル（交差部分）に基づくと、**健常者の人数は52名**です。

なお、研究者たちは、この分析ではサンプルサイズが小さいため、**健常者のみ**を基準コホートとするのではなく、**全コホート（健常者とDBD症例の両方）**を基準コホートとしてGPRモデルを訓練したことを述べています。しかし、より大きな解剖学的データセット $(n=248)$ で**健常者のみ**を基準コホートとして感度分析を行ったところ、結果は類似していたと報告されています。

Q: この検討では何種類のNormative Modelが作られましたか？

A: 

この検討では、**4種類**のノーマティブ・モデル（規範的モデル）が作成されました,。

ノーマティブ・モデルは、**年齢と性別**を関数として脳の発達パターンをモデル化するために、ガウス過程回帰（GPR）モデルを訓練することで作成されました。

このモデル構築は、以下の**4つのデータ・モダリティ**（データセット）のそれぞれについて行われました,。

1.  **ネガティブな顔** (Negative faces) - 機能的画像データ
2.  **ポジティブ/ニュートラルな顔** (Positive/neutral faces) - 機能的画像データ
3.  **図形（形状）** (Shapes) - 機能的画像データ
4.  **解剖学的画像** (Anatomy) - 構造的画像データ（ヤコビアン行列式を使用）,

これらのモデルは、各参加者について、**典型的な年齢に伴うパターンからの逸脱**を定量化する**ノーマティブ確率マップ（NPM）**を導出するために使用されました,。その後、これらの4つのモダリティの非閾値化された逸脱マップ（Z変換されたスコア）が、Linked ICA（LICA）によって統合されました。

（注：機能的データには $\text{N}=129$、解剖学的データには $\text{N}=127$ のサンプルが使用されましたが、どちらの場合も全コホート（健常者とDBD症例の両方）を基準コホートとしてモデルが訓練されました。）

Q: 

Anatomy Datasetを用いてNormative modelingしたときのN数は 50ですか？127ですか？

A: 

ご質問の、解剖学的データセット（Anatomy Dataset）を用いてノーマティブ・モデリングを行った際のサンプルのN数について、ソースには複数の数値が記載されているため、**分析の目的によってN数が異なります**。

ノーマティブ・モデリング（GPRモデルの訓練）に使われた主なサンプルサイズは**127名**です。

1.  **Linked ICAによる統合分析に使用されたノーマティブ・モデル（主要分析）:**
    *   Linked ICA（LICA）による機能的データ（fMRI）との統合分析に進んだ最終サンプルにおいて、解剖学的データ（構造スキャン）が利用可能であった参加者数は**127名**でした。
    *   この127名（症例群77名、コントロール群50名）の**全コホート**を使用して、脳構造（ヤコビアン行列式, JDs）のノーマティブ・モデルが訓練されました,。
    *   研究者たちは、このサンプルサイズが小さかったため、健常者（コントロール）のみを基準コホートとする代わりに、**全コホート（TDとDBDの両方）を基準コホートとして使用した**と述べています。

2.  **感度分析（Sensitivity analysis）で使用されたモデル:**
    *   より大きな解剖学的データセット（全248名、ケース154名、コントロール94名）を利用した**感度分析**も実施されました,。
    *   この感度分析では、**健常者（コントロール）のみ**を基準コホートとしてノーマティブ・モデルを構築した場合（N=94）、あるいは**全コホート**を基準コホートとしてモデルを構築した場合（N=248）の結果が、主要分析の結果と類似していることが確認されています,。

したがって、LICA統合分析で使用されたノーマティブ・モデルの訓練に直接用いられたN数は、**ケースとコントロールを合わせた127名**です。コントロール群単独の人数は50名です,。
