### 検討の全体的な目的

研究者たちは、**複数の異なる発達データソースを統合して大規模なデータセットを形成し**、それを利用して定型発達の若者における扁桃体結合性の経時的な変化（成長チャート）を作成しました。その後、この規範的範囲から精神病スペクトラム障害を持つ若者の発達の逸脱を評価しました。

### 各データセット（サンプル）の役割

#### データセットの組み合わせによる利点

この研究は、異なるサンプル（Luna 1、Luna 2、PNC、Pitt）を統合することで「ビッグデータ」アプローチを達成しました。これにより、扁桃体結合性の**規範的な発達軌跡**を構築するための大規模なデータセットが形成され、**発達曲線からの逸脱**を特定することが可能になりました。

特に、**Luna 1とLuna 2**は主に**定型発達の若者**のサンプルを提供し、研究の「成長チャート」の基盤となる年齢に関連した変化（発達効果）を特定するために使用されました。

一方、**PNCとPitt**は、精神病スペクトラム障害を持つ若者（およびその他の精神病理を持つ若者）のデータを提供し、定型発達群から導出された規範的範囲との比較を通じて、**精神病における年齢に関連した逸脱（disruption）**を特徴づけるために使用されました。

結果として、これらのマルチサイトデータセットを統合することで、サンプルの違いにもかかわらず、定型発達の若者における年齢に関連した変化のパターンが一貫していることが確認されました。

### Normative Modelingに使用されたデータの範囲

1.  **データの統合:** 研究者たちは、以前の研究（Luna 1とLuna 2に基づいている可能性のある研究）を拡張し、「**異なる発達データソースを組み合わせて大規模なデータセットを形成し**、扁桃体結合性の発達に関する規範的テンプレート（成長チャート）を構築する」というアプローチを採用しました。
2.  **対象群:** 規範的な年齢関連の変化（発達効果）を調べるために、**4つのサンプル全体にわたる定型発達対照群622名**のデータが使用されました。
3.  **統計的処理:** 統計分析（線形混合モデル, 3dLME）では、**定型発達対照群**を対象として、年齢（Age）と性別（Sex）に加えて**施設（Site）**を固定効果として含めることで、サイト間の違いを考慮しながら分析が行われました。
4.  **結果の検証:** 複数のサイトのデータ（Luna 1, Luna 2, PNC, Pitt）を統合したにもかかわらず、定型発達の若者における年齢に関連した変化のパターンは、**異なるサンプル間で驚くほど一貫していた**ことが確認されています。

Normative model（規範的モデル）の構築に用いられた**定型発達対照群（Typically Developing Group）**全体の年齢に関する加重平均（Weighted Mean Age）と統合標準偏差（Pooled Standard Deviation）を計算します。

Normative modelingには、以下の4つのサンプルに含まれる合計622名のデータが使用されました,。

| サンプル名 | 参加者数 (N) | 平均年齢 (Mean, $M_i$) | 標準偏差 (SD, $S_i$) |
| :--- | :--- | :--- | :--- |
| **Luna 1** | $N_1 = 213$ | $M_1 = 16.7$ | $S_1 = 3.0$ |
| **Luna 2** | $N_2 = 88$ | $M_2 = 19.5$ | $S_2 = 3.6$ |
| **PNC** | $N_3 = 292$ | $M_3 = 16.2$ | $S_3 = 3.4$ |
| **Pitt** | $N_4 = 29$ | $M_4 = 21.0$ | $S_4 = 2.7$ |
| **合計** | $N_{total} = 622$ | | |

ただし、ソースにはこれらのサンプルを統合した際の年齢の全体的な平均値や標準偏差は明記されていません。そのため、提供された数値に基づいて計算を行います。

### 1. 全体としての加重平均年齢 (Weighted Mean Age) の計算

加重平均年齢 ($M_W$) は、各サンプルの平均年齢にそのサンプルサイズをかけて合計し、総サンプルサイズで割ることで計算されます。

$$
M_W = \frac{\sum (N_i \times M_i)}{N_{total}}
$$

1.  $N_1 \times M_1 = 213 \times 16.7 = 3557.1$
2.  $N_2 \times M_2 = 88 \times 19.5 = 1716.0$
3.  $N_3 \times M_3 = 292 \times 16.2 = 4730.4$
4.  $N_4 \times M_4 = 29 \times 21.0 = 609.0$
5.  合計 $(3557.1 + 1716.0 + 4730.4 + 609.0) = 10612.5$

$$
M_W = \frac{10612.5}{622} \approx 17.06 \text{ 歳}
$$

統合された定型発達対照群（N=622）の**加重平均年齢は約 17.06 歳**です。

### 2. 統合標準偏差 (Pooled Standard Deviation) の計算

統合標準偏差 ($S_P$) は、各サンプルの分散（標準偏差の二乗）と自由度（$N_i - 1$）を用いて計算されます。

$$
S_P = \sqrt{\frac{\sum [(N_i - 1) \times S_i^2]}{\sum (N_i - 1)}}
$$

1.  $S_1^2 = 3.0^2 = 9.0; \quad (N_1 - 1) \times S_1^2 = 212 \times 9.0 = 1908.0$
2.  $S_2^2 = 3.6^2 = 12.96; \quad (N_2 - 1) \times S_2^2 = 87 \times 12.96 = 1127.52$
3.  $S_3^2 = 3.4^2 = 11.56; \quad (N_3 - 1) \times S_3^2 = 291 \times 11.56 = 3363.96$
4.  $S_4^2 = 2.7^2 = 7.29; \quad (N_4 - 1) \times S_4^2 = 28 \times 7.29 = 204.12$

5.  分子の合計: $(1908.0 + 1127.52 + 3363.96 + 204.12) = 6603.6$
6.  分母の合計（総自由度）: $\sum (N_i - 1) = (212 + 87 + 291 + 28) = 618$

$$
S_P = \sqrt{\frac{6603.6}{618}} = \sqrt{10.685...} \approx 3.27 \text{ 歳}
$$

統合された定型発達対照群の**統合標準偏差は約 3.27 歳**です。

*   **統合標準偏差 (Pooled Standard Deviation): 約 3.27 歳**
