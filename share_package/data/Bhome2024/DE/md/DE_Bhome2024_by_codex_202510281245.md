#### Deviation Metric
- **Answer**: Per-region z-scores relative to recalibrated norms; outliers defined as z < -1.96; total outlier count (sum across 169 regions); Hamming distance of binarised outlier patterns; supplementary liberal threshold z < -1.282.
- **Confidence Rating**: High

- **Supporting Text**: Z-scores were then generated... Outliers were defined as z-scores < -1.96... The total number of outliers across the 169 regions... Hamming distance was calculated using the vector of binarised z-scores... Using a more liberal outlier threshold (z-score < -1.282)...
- **Location**: Bhome2024.pdf.md:L108-L116; L116-L124; 1-s2.0-S2213158224000354-mmc1.md:L18-L26

- **Association Analysis**: Linear regressions adjusting for age and sex tested associations between total outlier count and composite cognitive score, MoCA, and visuoperception (HVOT); exploratory analyses with MDS-UPDRS, UMPDHQ, HADS; region-wise outlier proportions via Mann-Whitney U with FDR.
- **Key Findings Brief**: DLB shows higher and more variable total outlier counts and dissimilarity than PD; within PD, low visual performers have higher counts and dissimilarity than high performers; total outlier count associates with poorer cognition (DLB) and visuoperception (PD).
- **Key Findings Detailed**: DLB vs PD: total outlier count higher in DLB (mean 8.7 (SD 11.3)) vs PD (mean 3.6 (SD 6.0)); adjusted β = -5.60 (SE 1.74), p < 0.01. PD low vs high visual performers: adjusted β = -4.73 (SE 1.30), t = -3.64, p < 0.01. Dissimilarity (median Hamming) greater in DLB vs PD (W = 5649, p < 0.01) and PD low vs high visual performers (W = 522.5, p < 0.01). Associations: In DLB, higher total outlier count associated with poorer MoCA (β = -0.55 (SE 0.27), t = -2.04, p = 0.05) and composite cognitive score (β = -2.01 (SE 0.79), t = -2.54, p = 0.02); In PD, associated with worse visuoperception (β = -0.67 (SE 0.19), t = -3.59, p < 0.01).
- **Key Limitations**: Threshold choice for outlier definition may miss subthreshold effects, though results replicated with z < -1.282; site differences (UCL 3T vs NACC 1.5T; differing recruitment/assessments) could influence findings despite recalibration; NACC group had longer disease duration, possible selection bias at UCL.
- **Application Notes**: Applied adapted transfer learning to recalibrate a large pre-trained wBLR normative model (PCNToolkit v0.20) using local controls; summarised deviations as total outlier count and between-individual dissimilarity via Hamming distance; contrasted with conventional GLM analysis which was less sensitive.
