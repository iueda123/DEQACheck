
# AI に AIによるDE抽出結果も評価させる方法について

AIエージェントが抽出したdata extraction (DE) 結果を
AIに横断的に評価させる方法も確立したい。

複数のAIが生成したJSONを別のAIに横断的に読んでもらう。
このとき元データ（optimized）を参照させる。
各AIの報告の適切さ評価させ
総合的にみて適切な回答を再構築させる。
そのようなことを実現したい。


### 評価方法の核心部分

"適切" の基準とは何だろうか。適切の判断は難しい。
そこで、次の３つの観点で整理させ
人間が判断しやすい形、記録として適切な形で結果を提示させる。
最終判断はAIにさせない。３つの答えのうちどれを採用するかは人間に委ねる。

  * **1. 半数以上のツール＆モデルの判断を提示**
    * 全ての文献について、同じ条件（ツール＆モデル）のDEの結果が揃っている必要がある
    * ３か５か奇数個の結果が欲しい
  * **2. Detailが丁寧なツール＆モデルの判断を提示**
    * Detailを読んだ場合、もっとも丁寧に、そしてネガティブな（NR等の）結果に対してはより丁寧に思考しているものを信じたくはなる。
    * 良いDetailとは「適切なSorceを適切に依頼文に照らし合わせて適切な思考過程で回答を生成している。」
  * **3. 信頼性の最も高いツール＆モデルの判断を提示**
    * 全件を通じて、最も正確にSourceから情報を抽出する能力が高いツール＆モデルの組み合わせを把握する。
    * Comparation作業を繰り返してゆくうちに、精度が良いなと感じる、またいまいちだなと感じるツール＆モデルが出てくる。
    * 最も信頼に足るかどうかは全部をやってみないとわからない

### 補助情報
  * **最も信頼性の低いモデルの判断結果**
  * **意見の不一致率の提示**
  * **判断がブレやすいツール＆モデルの判断を提示**
    * 再度、調査をさせてみて、DE結果が変わるか、変わらないかというのも一つの判断材料であろう
    * すぐ結果が変わるようなツール＆モデルは信じがたい
    * 全件再抽出という手間がかかるので、抜き打ちも良いかもしれない。

## DE作業の出戻りを回避するために

DE結果をComparator上に並べて、眺めて、初めて自分が着目したかった "情報粒度・単位" 気づくことが多い。
そして後回する。もっとこういう観点で情報抽出してほしかった。

このような後悔を回避するための良い方策はなんだろうか。

Comparatorで、並べて（どのようにタブ階層をつくって）、比較し始めて、やっと
比較の観点が固まって来て、比較の情報粒度・単位が見えてくる。

例えばNMレビューで言えば、
論文別の情報に落とし込みたいのか、モデル別の情報に落とし込みたいのか、
疾患別の情報に落とし込みたいのか。

そうすると、DEプロンプトの不備が明らかになり、改めてAIに抽出依頼を出したくなってしまう。

そういう出戻りを回避するための方策として "tabulation" を最初から意識するのはどうだろうか。

出発点を「表にすることを目標として掲げる」にする。
表化を強く意識し、そして各行に対応させる情報粒度（整理観点）を決め、
各列に比較したい観点をあてがう。
そこまでを明確にしてから、情報抽出プロンプト、抽出JSON形式を考え、
その上でAIにDE依頼を出す。
