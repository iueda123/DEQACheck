### 有名データセットか否かの線引き

  * 名も無きデータセットをどう表現するか？
    * 研究チームが独自に集めたもの。
    * 一般公開されていないもの。
    * Originally collected dataset？「最初に収集された」とも読めるため、「著者ら自身が収集した」という意図が伝わりにくい可能性があり
    * In-house dataset — 神経画像研究で広く使われる表現で、「自施設で取得したデータ」というニュアンスが明確
  * 有名所のデータセットをどう表現するか？
    * 多数の研究で使われているもの。
    * 手続きなし、もしくは比較的簡単な手続きで利用ができるもの。
    * Publicly available dataset？ 公開されていてもマイナーなものは含めたくない、という趣旨に合わない場合があり
    * Established public dataset — 単に公開されているだけでなく、「確立された（多くの研究で使われている）」公開データセットであることを示せる
  * Established public dataset or not の分類基準（案）
    * 本レビュー対象論文内で5件以上の研究で使用されている
    * データセットへのアクセス方法（公式URL、データペーパー、申請手続き等）が確認できる
    * 上記いずれも満たすものを Established public dataset とし、それ以外を In-house dataset とする

### Response Variable
  * [正規化キーワード整理の記録（上田、2026年1月）](https://www.google.com/url?q=https://docs.google.com/document/d/1pDup9lvY12OeHOzHI2S41ntwIl9gIO3q6rJo162g0A4/edit?tab%3Dt.0&sa=D&source=editors&ust=1771453681718587&usg=AOvVaw1oQt-AqcCMOdxqldK14ebi)を参考に生成する。
  * キーワードの使い方に注意が必要。例えば以下。
    * SubV と GMVの使い分: SubV は「皮質下の特定ROI体積」を指す場合に用いる（例: 海馬、扁桃体、視床核、線条体、側坐核など）。 GMV は「灰白質体積の一般的指標」を指す場合に用いる（例: 全脳GMV、広域/皮質ROIのGMV、VBM由来のGM体積）。 迷った場合は、対象が明確に皮質下核の体積なら SubV、それ以外の灰白質体積は GMV に分類する。
    * CV と GMV の使い分け: 対象が「皮質（cortex）に限定された体積」であることが明確な場合は CV とする （例: FreeSurfer の cortical volume、表面ベースで thickness×area から算出された体積、皮質ROIのcortical GM volume）。 一方、VBM 由来のボクセル/領域の gray matter volume や、皮質下も含む灰白質体積、全脳GMVは GMV とする。 記述が曖昧で「gray matter volume」とだけある場合は GMV に寄せる。

### Site/Scanner Effect Handling

  * 明確なものを作る必要がある。現状は以下のようなものしかない。
  
```text
#### NM-7. Normative Modeling Validation with Handling Nuisance Structure
  * Extraction Criteria: Normative Modeling Validation with Handling Nuisance Structure
  * Extraction Result Style: ACRSL_Style
  * Notes:
    * Assess whether nuisance structure is appropriately handled in the normative modeling approach.
    * Nuisance structure includes: site/scanner effects, batch effects, QC metrics (motion, Euler), age nonlinearity, heteroscedasticity, non-Gaussian distributions, etc.
    * Consider methods used: harmonization (ComBat, etc.), hierarchical/random effects, transfer learning, inclusion of covariates, sensitivity analyses.
    * Answer should be: "Yes" (adequately handled), "Partial" (some but not all addressed), or "No" (not addressed).
  * Example (answer field):
    * Yes
    * Partial
    * No
```


### Model Build

  * 明確なものを作る必要がある。現状は以下のようなものしかない。

```text
#### NM-1. Model Origin
  * Extraction Criteria: Model origin and pre-training details
  * Extraction Result Style: ADCSL_Style
  * Notes:
    * In Answer, choose one: "New" or "Pre-trained".
    * In Detail, provide as applicable:
      - For Pre-trained: size and source of the pre-training dataset (N, number of sites); modeling method used for pre-training; key covariates included; reference to the original paper/resource; and whether/how the pre-trained model was adapted/calibrated for the current study.
      - For New: set Detail to "-".
    * Use concise wording; separate multiple sources with semicolons.
  * Example:
    * Answer: Pre-trained; Detail: Pre-trained BrainChart GAMLSS (N≈75k, multi-site); out-of-sample centiles; local calibration applied
```
